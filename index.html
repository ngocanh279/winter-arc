The game uses the real calendar date. When a new date is detected, the old route is archived, Energy resets, and a new route is generated. Cloud data follows the same engine.

Design Rules

CORE PHILOSOPHY
  • Adaptation beats perfection.
  • A disrupted day is an interruption, not a failure.
  • XP, skills and coins reward meaningful action.
  • Energy represents bandwidth, not worth.
  • The calendar drives the daily route — not the browser cache.
  • Cloud Save is the canonical cross-device backup when connected.
